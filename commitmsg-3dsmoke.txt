Fix the one-character bug that killed the 3D TPU run, and teach preflight to see metadata

MSFT FINE-TUNE: FAILED its pre-registered bar. best_gold_auc = 0.8968 against the
required > 0.9214 (parent raptor_ft_coatnet_v5_full_swa.pt). The decisive reading
is not that it stopped at 3 of 4 epochs -- it is that the warm start was damaged
immediately: the parent scores 0.9214 and epoch 0 scored 0.8795, then 0.8938,
then 0.8968. Below the parent from the first epoch and never recovering. That is
forgetting: bb_lr 3e-5 / head_lr 1e-3 over 3479 studies whose labels are mostly
text-model extractions from reports, pulling weights off good targets onto noisy
ones. Rejected on mechanism, not on a stopped run -- do not re-run this recipe.

GPU/TPU MISMATCH: kernel-tpu-msft has "enable_gpu": true, "enable_tpu": false, so
it never had torch_xla and ran on a T4 ("[tpu] no XLA ... -> dev=cuda") for 10.7 h
at 3.7 h/epoch, spending about a third of the weekly GPU quota on a run whose own
premise was never in force. Same family as the machine_shape trap: the flags and
the name disagreed and nothing compared them.

3D SMOKE: this one DID get a TPU (device xla:0, torch_xla 2.8.0, corpus loaded)
and died at ~75 s on
    TypeError: not all arguments converted during string formatting
at the first log line after the model is built. Cause: the format string has 5
placeholders but the args tuple passed 6 values, because the literal "1" inside
"input (1,%d,%d,%d)" was also supplied as an argument. Removed the extra 1.

An AST sweep of all 78 kernel scripts found exactly one real instance of this bug
class (the above). The only other hit, kernel-diag-slots/diag_slots.py:161, is a
false positive: "%s/%s" % key where key is a runtime 2-tuple.

scripts/preflight_queued.py gained two things, both aimed at this failure family:
  * a "meta" source kind that reads kernel-metadata.json, so a kernel NAMED tpu-*
    can be asserted to actually set enable_tpu -- source text alone cannot see the
    flags, which is exactly how the msft run slipped through;
  * a kernel_main.py fallback, since script kernels use either filename.
Four assertions now guard kernel-tpu-3dsmoke (fixed tuple present, 6-arg tuple
absent, enable_tpu true, enable_gpu false); preflight reports 0 problems.
