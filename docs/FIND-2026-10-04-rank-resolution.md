# FIND 2026-10-04：公榜的**名次**比**显示分**精细得多 —— 我们一直算错了目标

## 观测

`kaggle competitions leaderboard --download`，快照 **2026-10-04T04:13:29**：

```
队伍: 5068
我们: rank 708 · 0.943 · 40 次提交
0.943 这一格: 937 个队, 占 rank 344 .. 1280
铜牌线 (前 10%): rank 506
```

前一份快照（2026-10-03T12:23）：4981 队 · 我们 **677** · 0.943 格 **889 队 rank 326..1214** · 铜牌线 498。

## ⭐ 要点：**同一显示分，名次却是连续的**

如果 Kaggle 对同分并列，937 个队会**共享同一个 rank**。它们没有 —— 它们占据 344..1280 的
**连续独立名次**。⇒ **服务器按比 3 位小数更精细的真实分数排序**，显示层才做四舍五入。

### 这推翻了本仓一直在用的算术

| | 旧算法 | 新算法 |
|---|---|---|
| 目标 | "需要 +0.001 → 0.944"（按**显示分**跳一档） | 需要往格内上移 **202/937 = 21.6% 的格宽** |
| 格宽（真实分） | 0.001（=一格） | 0.001 |
| **所需真实提升** | **0.001** | **≈ 0.0002** |

⚠️ **假设**：格内真实分近似均匀分布。这不必然成立（前沿附近的密度未知），所以 0.0002 是
**量级估计**，不是精确值。但即便保守取两倍（0.0004），**仍远小于 0.001**。

### 直接后果：一批被我们"按分辨率归档"的改动，其实每一个都够用

| 改动 | 本地实测 | 是所需余量的 |
|---|---|---|
| MCL 加入 `_RAD_EXCLUDE` | **+0.000904** macro（n=3802/210pos, 35/35 同号） | **≈ 4×** |
| Fracture 移出 `_RAD_EXCLUDE`（C81） | **+0.00099** macro（n=4185, 五个标注源） | **≈ 4–5×** |
| `cn0` 第五视角 | +0.0028（parent-quality base） | ≈ 10× |

⇒ **它们不是"低于分辨率所以没意义"，而是"低于显示分分辨率、但高于名次分辨率"。**
本仓此前把这两件事混为一谈（F46 那次是同一类错误的另一个方向）。

## ⭐⭐ 而且：**名次本身就是一台更细的仪器**

`0.943` 格内 1 个名次 = 格宽的 **0.107%** ⇒ 名义分辨率 **~1e-6**。
仓库的核心前提——"公榜无法排序这些臂，只能取消资格"（A96）——**对显示分成立，对名次不成立。**

### 但它被赛场漂移污染，必须用【格内相对位置】而不是绝对名次

16 小时前后：

| | 10-03T12:23 | 10-04T04:13 |
|---|---|---|
| 队伍数 | 4981 | 5068（**+87**） |
| 0.943 格 | 889 队 | 937 队（**+48**） |
| 我们的绝对名次 | 677 | **708（−31）** |
| **格内百分位** | **39.5%** | **38.9%** |

⇒ 绝对名次掉了 31 位，**但那基本是赛场长大造成的**；格内相对位置只动了 **0.6 个百分点**。
**⇒ 净读数：`56798408`（M448 单折臂）没有可测地改善我们的真实分。**
这与它显示 0.942 一致，而且这次是**用一个比显示分细得多的仪器**读出来的，不是靠 3 位小数。

⚠️ 保留：0.6 个百分点 ≈ 0.000006 的分差，**在噪声内**，所以严格说这条臂是"无可测变化"，
不是"被证伪"。但方向与显示分一致，两条独立读数不矛盾。

## 该怎么办（可执行）

1. **终局两槽的判据要改。** 不再是"哪条臂显示分高"（它们全是 0.941–0.943），
   而是**哪条臂承载的【实测正向增量】总和最大** —— 因为所需余量只有 ~0.0002，
   而每条实测增量都是它的数倍。
   按此排序：**`0943cfm`**（cn0 +0.0028 · fracture +0.00099 · MCL +0.0009 = 三项实测）
   > **`0943cf`**（两项）> `0943cflat`（两项 + 路由对冲）> 其余。
   ⚠️ **`0943cf448` 的 M448 是外部证据、非本地实测**，且本次读数显示它没改善，**排在实测项之后**。
2. **把"格内百分位"加入常规读数**：每次 `leaderboard --download` 都记下
   `(rank − block_lo) / (block_hi − block_lo)`。它是唯一能看见 <0.001 变化的仪器。
3. ⚠️ **不要再用"低于 ±0.008 噪声所以没意义"来否决臂** —— 那句话对**排序显示分**成立，
   对**名次**不成立。B11/B12 的 ±0.008 是**绝对分**的标准误，不是**配对差**的分辨率
   （A118④ 早就记过：两个 ~95% 相同的提交之间，配对差分辨率 ≈ 0.0018）。
