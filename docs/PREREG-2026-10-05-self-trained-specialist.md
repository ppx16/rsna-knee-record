## 1. 它与 msft2 差在哪（为什么不算"再训一个同类"）

`docs/STRATEGY-2026-10-04-how-far-can-finetuning-go.md` §5 的止损规则明确禁止"同语料同配方的 CoAtNet 成员"
再来第三个，因为衰减已被实测量化（11×）。本实验在三处**同时**不同：

| | msft2 | **msft3-spec** |
|---|---|---|
| 损失 | 全 12 标签 BCE | **掩码到 6 个标签**（组外权重 0.0，无梯度） |
| 选点 | 全标签 macro AUC | **专科组 macro AUC** |
| 混入目标 | 作为第 6 个 Raptor 视角，全标签 | **只在 6 个标签上**混 |
| 目的 | 更准的通用成员 | **更准的那 6 个标签** |

⚠️ **第二条不是可选项。** `evaluate()` 返回的是全标签 macro，而训练循环按它选 best epoch。
只掩码损失而不改选点，等于**用一个目标训、用另一个目标选** —— 与"head 没被加载"是同一类错误，
而且它不会报错。构建器的探针里专门有 `_spec_auc > best` 与 `_spec_auc >= best` 两条。

**为什么是这 6 个标签**：不是我们挑的，是**基座自己的日志点名的** ——
*"Medial Meniscus / Medial OA / Lateral OA / Effusion / Synovitis / Contusion 是各臂真正不同、
外层权重只在这里起作用的地方"*。meniscus 预注册用的是同一句话。**两个实验共用一个假设，不各编一个。**

---

## 2. ⚠️ 我预期它大概率无效（写下来便于对账）

**方向：持平偏负。** 三条反对理由，都必须记在案：

1. **衰减 11×** 是在**这份语料**上测出来的。msft3-spec 仍然在这份语料上微调同一个架构；
   换损失只改了"学什么"，没改"从哪学"。
2. **它是 msft2 的兄弟，不是后代** —— 两者都从公开 v5 出发。兄弟设计的代价是：它没有 msft2 已经学到的东西，
   而它想超过的正是 msft2 在那 6 个标签上的表现。
3. **A167 成员门**：solo ≥ ~0.90，否则净有害。一个只训 6 个标签的模型，其**全标签** solo 必然难看；
   ⭐ 所以**本实验的成员门必须按 6 标签组计算，不能按全 12 标签** —— 否则会用错尺子把它否掉。
   这是本预注册唯一一处**主动偏离**既有门规的地方，理由写在上面。

## 3. 两档，先便宜后贵

| 档 | 配方 | 成本 | 何时跑 |
|---|---|---|---|
| **Tier 1** | `--freeze_backbone --epochs 8`：冻结整个 backbone，**只训 8 个头张量** | 分钟级 | 先跑这条 |
| **Tier 2** | 不冻结，`--epochs 4`，其余同 msft2 | ≈2.6 h | 仅当 Tier 1 在本地读出信号 |

命令：

```
python scripts/build_msft3_specialist.py --check              # 已通过
python scripts/build_msft3_specialist.py --build --head_only  # Tier 1
python scripts/build_msft3_specialist.py --build              # Tier 2
```

⚠️ `--build` **不推送**（`--push` 是独立开关，且是本预注册第 0 节的判断）。

**为什么先做 Tier 1**：`public0033` 本身就是个**冻结骨干上的专科头**。如果"冻结骨干 + 换损失"这种最廉价的形式
都读不出信号，那么 Tier 2 的 2.6 h 大概率是白花；反之若 Tier 1 有信号，Tier 2 是把同样的信号放大。

**为什么兄弟而不是后代**：warm start 用**公开 v5**（与 msft2 同一个父），而不是 msft2 的 SWA。
从 msft2 继续训会把 11× 衰减叠上去，几乎没什么可加。

## 4. 读数规则（先定，后看）

**本地仪器：870 研究的 OOF，不用 gold-58。** gold-58 的 bootstrap CI 是 **±0.021**（A83），
比我们要卡的任何带宽都宽，用它做判定会得到必然的"不显著"。

| 关卡 | 判据 |
|---|---|
| **零样本门**（构建器已内置，继承自 msft2） | 载入 warm start 后**未走任何梯度步**即评估，必须 ≥ **0.8963 − 0.002**。不过就**不训**（除非显式 `--allow_bad_warmstart`） |
| **本地入场门** | 6 标签组的 870-OOF macro AUC vs 父模型，做**配对 bootstrap**；**95% CI 必须不含 0**。这是本仓既有仪器（`gap0` 就是这么测出 +0.0119 [0.0041,0.0199] 的） |
| **成员门** | 按 **6 标签组**的 solo AUC ≥ 父模型对应值；达不到就**不接入** |
| **部署门** | 若全过：作为**第 7 个 Raptor 视角、仅在那 6 个标签上、w=0.10** 接入。提交前**必须取一次快照**，提交后与**新鲜快照**比，格内百分位要移动 **≥ 3 个百分点**才记为真实提升（止损规则的噪声量级） |
