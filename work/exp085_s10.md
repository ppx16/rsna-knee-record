## 10. ⚠️ The exp085 line CLOSES: the weights dataset was made private mid-session

Written 2026-10-01 ~08:40Z.

### 10.1 What happened

Pushing the fourth kernel (`rsna-knee-exp085-axis`) returned:

```
The following are not valid dataset sources and could not be added to the kernel:
    ['t88take/rsna-knee-t88-weights']
Kernel version 1 successfully pushed.
```

⚠️ **The push does not raise** — it reports success while silently dropping the dataset, and the kernel
would then die at `!! exp085 fold0.pt not mounted`. A direct check settled it:

```
dataset_list_files('t88take/rsna-knee-t88-weights')  ->  HTTPError 403 Forbidden
```

**The same call succeeded this morning** (it is how the checkpoint was listed, downloaded and
inspected). So the author **made the dataset private while this investigation was running.**

### 10.2 Why this closes the line rather than delaying it

* Our three gate kernels ran while it was public and their results stand; **`work/newckpt/fold0.pt`
  (360 MB) is still on this machine**, so the remaining experiments could in principle be re-run
  locally-built.
* But **a submission cannot attach what we can no longer access**, and re-publishing someone else's
  weights as our own dataset — which we could technically do — would be redistributing a checkpoint
  whose author has just withdrawn it. **That is not a thing this project should do**, and it is worth
  saying plainly rather than leaving it as an option in the file.

### 10.3 What was actually recovered, and what it is worth

| piece | how | result |
|---|---|---|
| module tree | 245/245 tensors, `strict=True`, 0 missing, 0 unexpected | ✅ proven locally **and** on Kaggle |
| **head order** | A vs B vs C, measured | ✅ **A**, +0.13 over B/C |
| **`eval_group_agg: mean`** | mean vs max vs median vs pooling | ✅ **mean**, +0.02; max/median ruled out |
| `slice_select band_groups` | 3 readings vs even spacing | ❌ eliminated (all worse) |
| `crop_mm 130.0` | 240–336 px | ❌ eliminated (≤0.016) |
| best gold58 macro-AUC reached | crop 272, order A, per-group mean | **0.8191** against the author's **0.9062** |

**0.8191 is below the A167 member gate (solo ≥ 0.90), so exp085 was never usable as a member**, and the
last 0.087 was traced to the corpus preprocessing — the one component that needed the author's own
code, which is private.

### 10.4 ⭐ The transferable lessons, which are worth more than the checkpoint

1. **A checkpoint is self-describing, and reading it beats guessing.** The config dict gave the head
   order, the group structure, the depth range, the crop and the resolution; two of those were
   recovered **as measurements** (+0.13 and +0.02) rather than assumptions.
2. **A shape-compatible, strictly-loading model can still be 0.09 wrong** — architecture is not a
   forward pass, and the forward pass is not the input pipeline. Three separate layers, each needing
   its own experiment.
3. **A public dataset can stop being public at any time.** Anything a submission must mount should be
   copied to a dataset **we** control *at the moment we first use it*, not at submission time. This
   project lost the ability to submit exp085 because it planned to keep attaching someone else's
   dataset — that is a planning failure, not bad luck.
4. ⚠️ **`kernels_push` reports success while silently dropping a dataset source it cannot attach.** It
   did not raise; it printed "successfully pushed". That is the same swallowed-failure class as the
   refused push and the dropped `ACTION6` coordinate, and the only defence is to read the warning
   output and assert the mount inside the kernel (which `--selftest`-style checks do).
